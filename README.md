# Sistem Informasi Inventaris Produk

Aplikasi Manajemen Produk (CRUD) berbasis PHP Native dan MySQL.

## Fitur
- **Create**: Menambah produk baru
- **Read**: Menampilkan daftar produk
- **Update**: Mengubah data produk
- **Delete**: Menghapus data produk

## Akses Lokal
`http://localhost/sistem%20informasi%20investaris%20produk/public`
